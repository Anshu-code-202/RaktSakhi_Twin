# RakhtSakhi Twin

An Explainable Software Digital Twin for Forecasting Short-Term Anaemia Risk in Indian Women.

## Problem
57% of Indian women aged 15–49 have anaemia. In rural clinics, nurses have limited Hb test kits and must decide who to test first.

## Solution
A web-based clinical decision support tool that forecasts a patient's 14-day risk of entering moderate anaemia (Hb < 10.9 g/dL), so clinicians can prioritize testing.

## Tech Stack
- Python 3.11+
- FastAPI (backend)
- Streamlit (dashboard)
- PostgreSQL (database)
- XGBoost + SHAP (ML + explainability)
